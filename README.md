A make.fun bounty entry: one brutally honest but still polite out-of-office auto-reply.

## Entry

> I'm away until Monday and will reply slowly — my inbox is a mountain I keep calling a molehill, so thank you for your patience.

## How it works

`main.ts` (Node 22) validates the reply — one sentence, 1–200 characters, not only white space — writes it to `/output/entry.txt`, then reads the file back byte-for-byte to confirm it matches.

```sh
node main.ts
```
